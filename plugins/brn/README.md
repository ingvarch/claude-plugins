# ccbrain

`brn` — компактная нотация, в которой агент хранит знания о проекте: один факт на строку,
сигил вместо заголовка, стабильные id вместо пересказа, отдельный файл `now` для handover.
Этот репозиторий одновременно плагин Claude Code.

## Установка плагина

```
/plugin install brn --marketplace ingvarch/ccbrain
```

Локально, без установки: `claude --plugin-dir ~/Repos/ingvarch/ccbrain`.

## Команды

| Команда | Что делает |
|---|---|
| `/brn:setup` | один раз на проект: создать `.brain/`, Claude заполняет `card` и `now` по репозиторию |
| `/brn:end` | ручной handover прямо сейчас (обычно не нужен, Claude делает его сам) |
| `/brn` | статус: есть ли мозг, сколько правок с последнего обновления `now` |

`/brn setup` и `/brn end` через пробел делают то же самое.

Дальше всё автоматически, пока в проекте есть `.brain/card`:

- `card`+`now` и протокол подмешиваются в system prompt. Снимок берётся один раз на сессию и после компакции, поэтому system prompt не меняется посреди разговора и кеш не ломается.
- Модель получает нативный инструмент `mcp__brn__brain` (`add`, `log`, `lint`, `slice`, `brief`, `status`) и пишет записи им, а не через shell.
- Ловушки в момент риска: когда Claude запускает Bash-команду, правит или читает файл, совпадающие строки из `traps` прикрепляются к результату инструмента. Каждая ловушка показывается раз за сессию.
- Каждый сабагент, запущенный через Agent tool, получает бриф в начало промпта: ключ, `card`, срез по `#тегам` из задачи, `now`. Записи `. ! ~ ?`, которые он вернёт, попадают в мозг как непроверенные (суффикс `?`), с дедупликацией.
- После хода, в котором Claude правил файлы, плагин сам запускает короткий ход обновления мозга и передаёт список правленых файлов. Если записывать нечего, Claude отвечает «brain current».
- Перед компакцией контекста плагин просит summary сохранить состояние handover дословно.
- Если в проекте есть `graphify-out/graph.json`, протокол и брифы отправляют структурные вопросы в graphify, а в `.brain` структурные факты не пишутся. При `/brn:setup` `GRAPH_REPORT.md` используется для выбора алиасов и лексикона.
- На старте сессии `.brain/` добавляется в глобальный gitignore машины (`core.excludesfile`, по умолчанию `~/.config/git/ignore`). Мозг живёт локально, в репозиторий не попадает.

Настройки (меню плагина или `pluginConfigs.brn` в settings): `autoHandover`, `minEdits` (по умолчанию 1), `globalIgnore`, `captureSubagentRecords`, `trapsAtRisk`.

Расширенные (для редких случаев, Claude сам использует `bin/brn` напрямую): `/brn slice #tag`, `/brn brief`, `/brn add <sigil> текст`, `/brn log`, `/brn lint`, `/brn start`, `/brn all`.

## Файлы

- `SPEC.md` — спецификация формата и протокол (для агентов, на английском).
- `hooks/brain.ts` — логика мозга на TypeScript: id, add, log, slice, brief, lint, сопоставление ловушек. Без доступа к движку, работает над интерфейсом файловой системы.
- `hooks/register.ts` — модуль плагина: хуки, команда `/brn`, инструмент `mcp__brn__brain`. Тесты в `hooks/register.test.ts`.
- `bin/brn` — те же операции POSIX-sh скриптом для людей, CI и других агентов. Плагин от него не зависит.
- `commands/setup.md`, `commands/end.md` — prompt-команды `/brn:setup` и `/brn:end`.
- `skills/brn-notation/SKILL.md` — краткая грамматика, подгружается агентом по требованию.
- `example/.brain/` — пример заполненного мозга проекта.
- `CLAUDE.snippet.md` — для проектов, где плагин не установлен.
